
# Sistem Informasi Mahasiswa (SIM)

## Deskripsi
Sistem Informasi Mahasiswa (SIM) merupakan aplikasi berbasis Laravel
yang digunakan untuk membantu pengelolaan informasi mahasiswa dan
program studi secara terstruktur.

## Fitur Aplikasi
- Login dan registrasi pengguna
- Dashboard statistik mahasiswa
- Pengelolaan data mahasiswa
- Pengelolaan data program studi
- Tambah, tampil, edit, dan hapus data

## Teknologi
- PHP 8.2
- Laravel 12
- SQLite
- HTML dan CSS
- JavaScript
- Git dan GitHub

## Persyaratan Instalasi
- PHP
- Composer
- Node.js dan NPM
- Git
